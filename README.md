# Smart Travel Planner

This project is a simple Python console program that helps a traveler plan a trip by collecting trip details, validating the main inputs, calculating travel-related expenses, and presenting a clean summary.

## What the program does

- Collects traveler information such as name, destination, traveler count, and trip length.
- Validates key inputs to avoid invalid values.
- Calculates:
  - total transportation cost
  - total hotel cost
  - hotel food cost estimate
  - total activity cost
  - overall trip cost
  - cost per traveler
  - average daily cost
- Uses built-in Python features only, including functions, dictionaries, input conversion, arithmetic, and formatted output.

## Built-in Python concepts used

- Variables and data types
- Type conversion with int() and float()
- Dictionary data structure for trip information
- Separate functions for each major calculation
- Parameters and return values
- Input validation
- Formatted console output

## How to run

1. Open a terminal in the project folder.
2. Run the script:

   python smart_travel_planner.py

3. Enter the requested trip information when prompted.

## Example

The program will ask for:

- traveler name
- destination
- number of travelers
- number of travel days
- transportation cost per traveler
- hotel cost per day
- activity cost per traveler

It then prints a final travel summary with totals and cost breakdown.

## Notes

This is a beginner-friendly program designed to demonstrate core Python concepts in a practical travel planning example.
